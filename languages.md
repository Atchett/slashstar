# Languages

Slash Star designs are often based on specific programming languages, but the choice of language is never arbitrary or exhaustive.

Languages are included when there is a clear visual or conceptual reference that translates well into a minimal design.

## Selection Principles

When a language is used as the basis for a design, it is chosen because it offers at least one of the following:

- recognisable syntax or structure
- widely understood concepts within the developer community
- a visual form that works without explanation

The goal is familiarity rather than completeness.

## Representation

Language-based designs focus on small, specific ideas rather than logos or mascots. This might include:

- a single line of syntax
- a well-known language feature
- a pattern developers instantly recognise

Designs are not intended to signal expertise or affiliation. They are references, not endorsements.

## Scope

Not every language is represented, and new designs are added selectively.

Slash Star is intentionally limited in scope, prioritising clarity and restraint over coverage.

## Current Language References

At present, Slash Star includes designs inspired by a small number of programming languages where the underlying concepts translate cleanly into minimal visual form.

Examples include:

- C
- CSS
- Go
- Python
